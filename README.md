# Genetic Algorithm Toolbox & Capacitated Vehicle Routing Problem (CVRP)

A modular, object-oriented Genetic Algorithm (GA) toolbox implemented from scratch in Python, and its application to solve the **Capacitated Vehicle Routing Problem (CVRP)** benchmark without third-party optimization or GA libraries.
